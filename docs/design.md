# 設計：動物小餐廳

> 小朋友開一間動物餐廳，邊煮邊學。2026-11-06 定案（見最後「已經決定的事」）。畫面草圖在 `docs/mockups/`。和「畫畫小鎮」「字母寵物」是同一個作者的兄弟 APP，同一套技術，畫風不同。

## 給誰
- 3～6 歲，在台灣，國語為主；家長會一起看。
- 不連網、不定位、沒有廣告、沒有帳號（和兩個兄弟 APP 一樣）。

## 核心想法：開一間動物小餐廳
- 動物客人來點餐。點餐單**只有圖**（3 片番茄的三明治），不用識字。
- 小朋友照「圖片食譜卡」一步一步做，做好端給客人，客人開心地吃。
- 做菜的每一個動作都是一個小遊戲：切、攪、打蛋、翻面。玩的時候就學到東西，不會覺得在上課。

## 一邊玩一邊學什麼
| 能力 | 在遊戲裡怎麼學 |
|---|---|
| 數數、數量 | 放 3 片番茄、打 2 顆蛋；切的時候數「1、2、3」；市場付錢 |
| 顏色、形狀、大小 | 挑紅色的番茄、把吐司切成三角形、大碗和小碗 |
| 順序（做事的步驟） | 圖片食譜卡：洗手 → 洗菜 → 切 → 煮 → 裝盤 |
| 均衡飲食 | 國民健康署「我的餐盤」六句口訣變成配餐遊戲 |
| 安全和衛生 | 先洗手；兒童安全刀；爐火、熱鍋、熱水出現「請大人幫忙」 |
| 手部動作 | 切是直線、攪拌是畫圓、揉麵是來回、包水餃是捏：也是寫字前的手部練習，和字母寵物互相呼應 |
| 台灣的食物和節日 | 蛋餅、珍珠奶茶、水餃、滷肉飯；冬至湯圓、端午粽子、中秋月餅、過年年菜 |
| 中英單字 | 每樣食材念國語，再念英文（番茄，tomato） |
| 耐心、照顧別人 | 等鍋子變金黃再翻面；端給客人，看客人開心 |

## 主要玩法
1. **點餐**：客人頭上有圖片點餐單，小朋友按「開始做」。
2. **食譜卡**：4～6 個步驟的圖，做完一步打勾；做過幾次以後可以把卡片收起來，自己記步驟。
3. **做菜小遊戲**，一個動作一種手勢：
   - 洗：手指在菜上搓，冒泡泡。
   - 切：手指滑過虛線，一刀一片，邊切邊數。
   - 打蛋：點兩下敲開。
   - 攪拌：手指畫圈。
   - 倒：把杯子拖過去、斜斜倒。
   - 揉、桿：手指來回。
   - 包：捏兩邊（水餃、飯糰）。
   - 煎和翻面：看顏色變金黃，往上滑翻面。
   - 裝盤：自由擺、撒裝飾。
4. **自由廚房**：沒有食譜，什麼都能加；客人會有好笑的反應（「草莓配滷肉？嗯⋯⋯好特別！」）。玩創意，不會失敗。
5. **市場買菜**（5 歲以上）：圖片購物清單、價格牌，用 1 元、5 元、10 元銅板付錢。
6. **我的餐盤**：照口訣配一份均衡的餐（每天早晚一杯奶、每餐水果拳頭大、菜比水果多一點、飯跟蔬菜一樣多、豆魚蛋肉一掌心、堅果種子一茶匙）。
7. **小菜園**（之後）：種番茄、小白菜，每天澆水，幾天後收成，知道食物從哪裡來。和寵物一樣不會枯死。
8. **食譜圖鑑**：做過的菜收集起來；同一道做 3 次得到金星。

## 和真實生活連結
- 「一起做做看」：幾道不用火的簡單食譜（水果串、優格杯、三明治、飯糰），在家長模式有真的做法、材料和安全提醒，週末可以和小朋友在家裡真的做一次。

## 健康的設計原則（和兩個兄弟 APP 一樣）
- **不會失敗**：燒焦了只說「哎呀，下次早一點翻面」，客人還是會吃。
- **不催促**：沒有倒數扣分。等的時候看顏色變化，不是看時間。
- **不賣東西給小朋友、沒有廣告**：金幣只能從做菜得到，只能換餐廳的裝飾。
- **不鼓勵垃圾食物**：有甜點，但客人會說「偶爾吃一點點」；我的餐盤配得均衡，客人最開心。

## 畫風（三選一，見 `docs/mockups/0_畫風選擇.png`）
要和畫畫小鎮的粗框貼紙、字母寵物的水彩繪本都不一樣。
- **A 黏土風（建議）**：像捏黏土做的，圓圓胖胖、有立體感和小小的手指印，沒有框線。食物看起來很好吃、很想摸，和「動手做」很搭。
- **B 剪紙拼貼風**：一片一片紙剪下來貼的，邊緣有點毛、有紙的紋路和疊起來的影子。
- **C 扁平明亮風**：乾淨的幾何形狀、鮮豔的顏色，最簡單清楚。

## 家長模式（要過家長關卡）
- 看做了哪些菜、數數和餐盤玩得怎麼樣。
- 難度：3～4 歲數到 5、不用錢；5～6 歲數到 10、市場要付錢。
- 「一起做做看」的真實食譜卡。
- 聲音、語音、每天可以玩多久。
- 以後的「完整版」購買只在這裡。

## 以後上架和收費（和兩個兄弟 APP 一樣）
- 免費下載：餐廳和 5 道菜。
- 一次買斷完整版：全部食譜、市場、菜園、節日料理、自由廚房的裝飾。
- 購買只在家長模式，小朋友的畫面沒有購買按鈕和廣告。

## 技術（和兩個兄弟 APP 一樣）
- Flutter（Android 和 iOS）、Riverpod、flutter_svg、audioplayers、flutter_tts。
- 圖和聲音都用程式產生；觸控用原始的手指事件，一碰就有反應。
- 存檔是手機裡的一個小檔案。

## 0.1 的五道菜和步驟
每一步是一個小遊戲；數量照點餐單（3～4 歲 1～5，5～6 歲到 10）。
| 菜 | 客人 | 步驟 |
|---|---|---|
| 番茄起司三明治 | 小熊 | 洗手 → 洗番茄（搓）→ 切番茄（切 N 片，邊切邊數）→ 疊起來（麵包、起司、N 片番茄、麵包）→ 切成三角形 → 上菜 |
| 水果串 | 小兔 | 洗手 → 洗水果 → 切香蕉（N 塊）→ 照規律串起來（草莓、香蕉、草莓、香蕉⋯⋯）→ 上菜 |
| 蛋餅 | 小貓 | 洗手 → 打蛋（N 顆）→ 攪一攪（畫圈）→ 請大人開火 → 倒蛋液 → 等變金黃 → 放餅皮、翻面 → 捲起來 → 切成 N 塊 → 淋醬油膏 → 上菜 |
| 珍珠奶茶 | 小鴨 | 舀珍珠（N 匙）→ 放冰塊（N 顆）→ 倒茶（倒到線）→ 倒牛奶（倒到線）→ 搖一搖 → 蓋蓋子、插吸管 → 上菜 |
| 水餃 | 小豬 | 洗手 → 包水餃（N 顆：放餡、捏起來）→ 請大人燒水 → 一顆一顆放進鍋子 → 等浮起來 → 撈起來 → 上菜 |

## 畫面
1. **餐廳**（首頁）：櫃台、客人和圖片點餐單、「開始做」、金幣和星星、食譜書、家長的鎖。
2. **廚房**：上面一排食譜卡的步驟，中間是現在這一步的小遊戲，做完一步「叮」，下一步。
3. **上菜**：回到餐廳，客人吃、開心、給金幣和星星，下一位客人。
4. **食譜書**：做過的菜和次數，做 3 次得到金星。
5. **家長模式**：難度（3～4 歲、5～6 歲）、英文、聲音、語音、真實食譜卡、完整版。

## 聲音
- 背景音樂：餐廳、做菜、食譜書各一首；全部用程式合成。
- 音效：每個動作都有（洗、切、打蛋、攪拌、倒、煎、翻面、放進鍋子、滾、搖、擠醬），做完一步「叮」，做完一道菜和上菜有開心的音樂；每位動物客人有自己的開心叫聲。
- 語音：念步驟、數數、食材的國語（家長可以打開英文）。

# 動物小餐廳的聲音

所有聲音都是用程式合成的（numpy、scipy）：沒有錄音、沒有下載別人的素材，曲子都是為這個 APP 新寫的。合成用的小工具（鐘聲、木琴、接成循環、動物聲音的共鳴方法）是從字母寵物的 `design/sounds/make_sounds.py` 複製過來的；新做的樂器有烏克麗麗、拇指琴（卡林巴）、陶笛、撥弦低音和小小的金屬聲。

## 怎麼產生

```
pip install numpy scipy                                     # 只要第一次
python3 design/sounds/make_sounds.py                        # 寫到 app/assets/sounds/*.wav
python3 design/sounds/make_sounds.py preview 試聽.m4a        # 再做一個試聽檔（要 ffmpeg）
```

跑完會印出每個檔案的長度、大小、音量、有沒有破音，還有背景音樂接頭的檢查。亂數都用固定的種子，每次跑出來的檔案都一模一樣。試聽檔是每首背景音樂的前 8 秒，接著每個音效照順序播一次，中間停一下，會印出每一段從第幾秒開始。

## 格式
- 全部是 WAV、單聲道、16 位元。
- 背景音樂 16,000 Hz；音效和客人的聲音 22,050 Hz。
- 背景音樂都是整數小節，可以無縫循環：曲子結尾還在響的聲音接回開頭，聽不出接縫。
- `sizzle`（煎東西）也可以無縫循環，讓 APP 一直播到煎好：它沒有淡入淡出，頭尾都停在聲音剛好穿過 0 的地方，不會「啪」一聲。
- 音量（滿格是 1）：背景音樂最大 0.24～0.28；音效 0.28～0.72，都在 0.75 以下。其他音效兩頭都有淡入淡出。
- 每個音效聽起來差不多大聲（用耳朵比較敏感的頻率來量，差在幾 dB 以內）。「哎呀」（`oops`）是柔和的笛聲，所以最大音量調得比較小。
- 手機小喇叭放不出很低的聲音，所以熊的「嗯！」、鍋子冒泡這些低低的聲音，都加了一點比較高的聲音，手機上才聽得到。
- 全部加起來約 2.9 MB（3,019,364 bytes），在 4 MB 以內。

## 背景音樂

| 檔案 | 用在哪裡 | 長度 | 聽起來 |
|---|---|---|---|
| `music_restaurant` | 餐廳（客人來點餐） | 19.2 秒 | C 大調、搖擺節奏的小咖啡廳曲子。烏克麗麗刷和弦、撥弦低音、沙鈴和輕輕的木頭聲；木琴唱旋律、鐵琴在上面閃閃的，後半段換陶笛唱。結尾是店門口的小鈴鐺「叮－叮」 |
| `music_cooking` | 做菜 | 21.1 秒 | F 大調，忙碌但輕輕的、很穩。木琴一直咚咚咚地跑，木魚像廚房計時器一樣「滴－答」，沙鈴和小鼓，烏克麗麗在第二、四拍輕輕刷。鐵琴的旋律留了空，空的地方湯匙敲鍋子「叮叮」；後段換烏克麗麗彈旋律 |
| `music_book` | 食譜圖鑑、安靜的畫面 | 21.8 秒 | A 大調，慢慢的。拇指琴唱旋律，烏克麗麗輕輕地上下撥，低音和溫暖的長音托著；每半首結尾有一串小鐵琴聲 |

## 客人的聲音

卡通的聲音，不是真的動物叫聲；每個客人都是開心的「嗯！」或笑聲，音高和音色都不一樣（熊最低，兔子最高）。

| 檔案 | 客人 | 聽起來 |
|---|---|---|
| `voice_bear` | 熊 | 低低暖暖的「呵呵」，再一聲開心的「嗯－哼！」 |
| `voice_rabbit` | 兔子 | 高高的、很快的「嘻嘻嘻嘻－嘻！」 |
| `voice_cat` | 貓 | 打呼嚕一樣的「嗯嚕嚕」，再一聲亮亮的「咪！」 |
| `voice_pig` | 豬 | 鼻子哼哼笑「哼哼哼」，再一聲「嗯！」 |
| `voice_duck` | 鴨子 | 嘎嘎的開心笑聲「哇哇哇哇」，一聲比一聲高 |

客人的聲音和兩個兄弟 APP 一樣：用一個嗡嗡聲（聲帶）通過幾個共鳴（嘴巴的形狀），做出「嗯」「嘻」「哇」這些聲音。
